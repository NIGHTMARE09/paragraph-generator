# Paragraph Generator

A simple React application that generates random paragraphs based on user input.

## Features

- Generate paragraphs with a specified number of words
- Random word ordering using Fisher-Yates shuffle algorithm
- Responsive design with sticky controls
- Error handling and loading states

## Technologies Used

- React.js
- React Hooks (useState, useCallback)
- Fetch API

## How to Use

1. Enter the desired number of words in the input field
2. Click the "Generate" button
3. The application will fetch random words and create a paragraph
4. For large paragraphs, use the scroll-to-top button to navigate back to the controls

## Installation

```bash
# Clone the repository
git clone https://github.com/YOUR-USERNAME/paragraph-generator.git

# Navigate to the project directory
cd paragraph-generator

# Install dependencies
npm install

# Start the development server
